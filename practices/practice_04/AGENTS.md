# Основные правила проекта

- основной код находится в intervals.py
- тесты находятся в дирректории tests/
- основной способ проверки: make test
- изменения должны быть минимальными и соответствовать существующему стилю
- нельзя отключать или удалять тесты ради прохождения проверки
- после изменения Python кода необходимо запускать проверку
- перед завершением задачи все тесты должны проходить
