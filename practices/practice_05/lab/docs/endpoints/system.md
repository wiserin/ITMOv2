# System — диагностика HTTP-процесса

## GET /ping

Назначение: проверить, что HTTP-процесс AnimeMap API отвечает. Используется Docker healthcheck сервиса backend.

Доступ: публичный, cookie и роль не требуются. Параметров и тела запроса нет.

Успех: `200 OK`, JSON-строка:

```json
"pong"
```

Путь не имеет префикса `/v1`. Это heartbeat HTTP-процесса, а не запрос к бизнес-сущностям. Подключения к PostgreSQL и Redis проверяются в startup lifespan; Compose также отдельно проверяет их собственными healthcheck.

При незавершённом или неудачном startup сервер не начинает обслуживать запросы. Полное локальное окружение описано в [deployment.md](../deployment.md).
