# Кодстайл Python

## Длина строки

- Максимальная длина строки кода — **70 символов**, включая отступ.
- Правило применяется ко всему Python-коду бэкенда: application,
  domain, infrastructure, presentation, тестам, миграциям и run.py.
- Комментарии и docstring также должны укладываться в 70 символов.
- Длинные вызовы, импорты, коллекции и выражения переносятся внутри
  скобок. Длинные литералы разбиваются на соседние строки без изменения
  значения. В коллекциях такая конкатенация заключается в скобки.
- Не обходить правило через noqa, отключение E501 или исключение файлов.
- Лимит задан в backend/pyproject.toml: Ruff line-length = 70,
  lint.extend-select = ["E501"].

## Сигнатуры и отступы

- В многострочной сигнатуре параметры имеют отступ на 8 пробелов
  глубже строки def/async def; для методов учитывается отступ класса.
- Закрывающая скобка, возвращаемый тип и двоеточие остаются на строке
  последнего параметра. Сложные аннотации переносятся внутри скобок
  либо выносятся в понятный типовой алиас, соблюдая лимит 70 символов.
- Тело функции имеет обычный отступ в 4 пробела относительно def.
- Многострочное наследование класса оформляется аналогично:
  базовые классы с отступом 8 пробелов, скобка на последней строке.
- Используются пробелы без смешивания с символами табуляции.
- Автоформатирование должно сохранять эти правила сигнатур.

```python
async def login(
        data: LoginRequest,
        response: Response,
        use_case: LoginUseCaseDI) -> LoginResponse:
    result = await use_case.login(data.to_dto())
    return LoginResponse.from_dto(result)
```
